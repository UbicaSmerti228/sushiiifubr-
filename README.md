# Фудкост

Считает себестоимость роллов, сетов и пиццы по закупочным ценам. Показывает, какие блюда тянут прибыль вниз, где на кухне пропадают продукты и сколько закупить на неделю.

Сделано для небольших доставок суши, где меню живёт в `menu.json` на сайте, а себестоимость считают в тетради или не считают вовсе. Работает в браузере, без регистрации и сервера.

Сайт: https://ubicasmerti228.github.io/sushiiifubr-/ (если включён GitHub Pages: Settings → Pages → ветка `main`).

## Вкладки

**Меню.** Все блюда с ценой, себестоимостью, фудкостом и маржой. Блюда дороже цели выделены. Сортировка по категориям, по фудкосту, по марже.

**Блюдо.** Техкарта: продукты в граммах, миллилитрах или штуках, упаковка, другие блюда (так собираются сеты). Видно, какая нужна цена, чтобы уложиться в цель, и её можно поставить в одно нажатие. Если часть заказов идёт через агрегатор, показана маржа и там. Техкарту можно распечатать.

**Продукты.** Цена за упаковку, как в накладной, и процент отхода при разделке. После правки цены сверху появляется список блюд, которые это задело, «было / стало», и кнопка вернуть старую цену. Рядом видно, насколько продукт подорожал за полгода.

**Продажи.** Сколько порций продано за период. Можно вставить из кассы или Excel: строка на блюдо, название и количество.

**Анализ.**
- Деньги за период: выручка, продукты, комиссия агрегатора, постоянные расходы, прибыль.
- Точка безубыточности: сколько порций в день нужно продавать, чтобы выйти в ноль.
- Меню-инжиниринг: матрица «звёзды, рабочие лошадки, загадки, собаки» с советом для каждой группы. Для лошадок посчитано, сколько даст подъём цены на 30 ₽.
- «Что если подорожает»: выберите продукт и процент. Видно, сколько денег уйдёт за период, какие блюда выйдут за цель и на сколько поднять каждую цену, чтобы ничего не потерять.

**Сверка.** Сколько продукта должно было уйти по техкартам на эти продажи и сколько ушло на самом деле по остаткам. Разница в килограммах и рублях: перевес порций, списания, то, что ушло мимо кассы.

**Закупка.** Сколько купить на N дней с запасом, если продажи пойдут как в прошлом периоде, за вычетом остатков. Округляется до целых упаковок. Список копируется одной кнопкой, чтобы отправить поставщику.

**Файлы.**
- Импорт `menu.json` с сайта. Сеты, у которых в описании по строкам перечислены роллы, собираются из них сами. Роллы, которых нет в меню (только для сетов или с опечаткой), можно завести отдельными блюдами.
- Ссылка с данными: вся база сжимается прямо в ссылку. Отправили в WhatsApp, открыли на телефоне, данные те же. На сервер ничего не уходит.
- Сохранение и открытие файлом `.json`.

## Как начать

1. Во вкладке «Продукты» замените условные цены примера на свои.
2. Во вкладке «Файлы» загрузите `menu.json` сайта или добавьте блюда вручную.
3. Заполните состав роллов. Сеты посчитаются, когда будут заполнены роллы внутри. До этого в меню написано «нет состава у N».
4. Внесите продажи за месяц, постоянные расходы и, если есть, долю заказов через агрегатор.
5. Раз в месяц пересчитайте остатки и посмотрите «Сверку».

## Формат menu.json

Массив объектов. Нужны `name` и `price`, остальное по желанию:

```json
[
  { "name": "ФИЛАДЕЛЬФИЯ", "category": "klassicheskie_rolly", "price": 560 },
  { "name": "ФИЛАМАНИЯ", "category": "sety", "price": 1450,
    "description": "Филадельфия\nФиладельфия Грин\nФиладельфия с ананасом\n\nВес: 24шт/690гр" }
]
```

Если цены нет, но есть `sizes`, берётся цена первого размера. Строки «Вес: …» в описании пропускаются. Регистр и «ё/е» в названиях не важны.

## Как считается

- Цена грамма = цена упаковки / (размер упаковки × 1000) / (1 − отход).
- Себестоимость блюда = продукты + блюда внутри набора (без их упаковки) + упаковка самого блюда.
- Фудкост = себестоимость / цена. Наценка = (цена − себестоимость) / себестоимость.
- Рекомендуемая цена = себестоимость / цель, округлённая вверх: до 10 ₽, до 50 ₽ или на 90 (490, 590), как выбрано в шапке.
- Маржа с учётом агрегатора = цена − себестоимость − цена × доля заказов × комиссия.
- Меню-инжиниринг по методу Kasavana и Smith. Блюдо популярное, если его продажи не меньше 70% от средней доли на блюдо. Маржа высокая, если не ниже средней, взвешенной по продажам.
- Точка безубыточности = постоянные расходы за период / средняя маржа с порции.
- Сверка: по факту = остаток на начало + пришло − остаток на конец. По техкартам = продажи × граммы в техкарте / (1 − отход).

## Ограничения

- Данные хранятся в браузере. На другом устройстве их не видно, пока не откроете ссылку или файл.
- В режиме инкогнито после закрытия вкладки всё пропадёт.
- Продажи вносятся вручную или вставкой. Связи с кассой нет.
- Комиссию агрегатора нужно взять из своего договора. В примере стоит 25% просто для наглядности.
- Набор, собранный при импорте, берёт каждое блюдо по одной штуке. Если «Снек микс» состоит из половины порции фри, поправьте количество на 0,5.
- Ссылка с данными для меню на 150+ блюд выходит длинной. Если мессенджер её обрежет, передайте файлом.
