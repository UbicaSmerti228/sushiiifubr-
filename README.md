# Фудкост

Считает себестоимость роллов, сетов и пиццы по закупочным ценам. Показывает, какие блюда продаются дешевле, чем надо, и что пересчитать, когда подорожал лосось.

Сделано для небольших доставок суши, где меню живёт в `menu.json` на сайте, а себестоимость считают в тетради или не считают вовсе.

Сайт: https://ubicasmerti228.github.io/sushiiifubr-/ (если включён GitHub Pages: Settings → Pages → ветка `main`).

## Что умеет

- Продукты с ценой за упаковку, как в накладной, и процентом отхода при разделке. Чистая цена за кило считается сама.
- Техкарта блюда: продукты в граммах, миллилитрах или штуках плюс упаковка. Показывает себестоимость, фудкост, маржу и наценку.
- Сеты собираются из других блюд. Поменяли состав «Филадельфии», и все сеты с ней пересчитались.
- Цель по фудкосту (по умолчанию 35%). Блюда дороже цели выделены. Для каждого видно, какая нужна цена, и её можно поставить в одно нажатие.
- После правки цены продукта сверху появляется список блюд, которые это задело, с фудкостом «было / стало». Старую цену можно вернуть.
- Импорт `menu.json` с сайта доставки: названия, цены, категории. Сеты, у которых в описании по строкам перечислены роллы, собираются из этих роллов сами.
- Если в сете есть ролл, которого нет в меню (только для сетов или с опечаткой в названии), импорт покажет список и может завести такие роллы отдельными блюдами.
- Печать техкарты одного блюда.
- Сохранение и открытие своих данных файлом `.json`.

## Как пользоваться

1. Во вкладке «Продукты» замените условные цены примера на свои.
2. Во вкладке «Импорт и файлы» загрузите `menu.json` сайта или добавьте блюда вручную.
3. Откройте блюдо и заполните состав. Сеты посчитаются, когда будут заполнены роллы, из которых они состоят. До этого в меню будет написано «нет состава у N».

## Формат menu.json

Массив объектов. Нужны `name` и `price`, остальное по желанию:

```json
[
  { "name": "ФИЛАДЕЛЬФИЯ", "category": "klassicheskie_rolly", "price": 560 },
  { "name": "ФИЛАМАНИЯ", "category": "sety", "price": 1450,
    "description": "Филадельфия\nФиладельфия Грин\nФиладельфия с ананасом\n\nВес: 24шт/690гр" }
]
```

Если цены нет, но есть `sizes`, берётся цена первого размера. Строки «Вес: …» в описании пропускаются. Регистр и «ё/е» в названиях не важны.

## Как считается

- Цена грамма = цена упаковки / (размер упаковки × 1000) / (1 − отход).
- Себестоимость блюда = сумма продуктов + сумма блюд внутри набора (без их упаковки) + упаковка самого блюда.
- Фудкост = себестоимость / цена. Наценка = (цена − себестоимость) / себестоимость.
- Рекомендуемая цена = себестоимость / цель, округлённая вверх до 10 ₽.

## Ограничения

- Данные хранятся в браузере. С другого компьютера или из другого браузера их не видно, пока не сохраните файл и не откроете его там.
- Если сайт открыт в режиме инкогнито, после закрытия вкладки всё пропадёт.
- Набор, собранный при импорте, берёт каждое блюдо по одной штуке. Если «Снек микс» состоит из половины порции фри, поправьте количество на 0,5.
- Расход продуктов на заготовку (рис, который выбросили в конце смены) не учитывается. Его можно заложить в процент отхода.
